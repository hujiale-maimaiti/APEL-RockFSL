# Dataset Download

The experiments use the **Photomicrograph Dataset of Rocks for Petrology Teaching at Nanjing University**.

Official dataset download:

https://doi.org/10.11922/sciencedb.j00001.00097

The dataset is organized into class-disjoint `meta_train`, `meta_val`, and `meta_test` subsets using a 78/10/20 class split.
